# Creator Marketplace for Hiring Video Editors & Designers

## Overview

Creator Marketplace is a web-based platform that connects clients with video editors and designers for creative projects.

Clients can discover creators, view their profiles and portfolios, post projects, send hiring requests, and manage project progress.

Creators can create professional profiles, showcase their portfolios, browse available projects, receive hiring requests, and manage their accepted projects.

## Problem

Clients may find it difficult to identify suitable video editors and designers based on their skills, experience, portfolio, and pricing.

At the same time, creators may find it difficult to showcase their work and discover relevant project opportunities.

This platform provides a structured marketplace to connect clients and creators through a centralized hiring workflow.

## Key Features

- User registration and login
- Role-based access for Client, Creator, and Admin
- Creator profile management
- Portfolio management
- Project posting
- Creator and project browsing
- Hiring request management
- Project status tracking
- Reviews and ratings
- Admin management

## User Roles

### Client

- Create account and login
- Post projects
- Browse creators
- View creator portfolios
- Send hiring requests
- Track projects
- Give reviews and ratings

### Creator

- Create account and login
- Create creator profile
- Add skills and experience
- Manage portfolio
- Browse available projects
- Accept or reject hiring requests
- Manage project status
- View reviews

### Admin

- Manage users
- Monitor projects
- Monitor hiring requests
- Manage platform activities
